# 心宠 AI 双层实时联调演示设计

## 目标

在 `/pet-ai-management` 的“实时联调”页签中展示会议确定的双层 AI 链路。第一层心宠 AI 负责学生日常对话和个性化表达；检测到负面情绪后，把内容交给第二层“小芯 AI”专业咨询师演示层，再由心宠 AI 将专业建议转述给学生。实体链路继续使用百度 ASR/TTS 和阿里云 OpenAI 兼容模型。

## 产品边界

- [x] 测试学生 `stu-test` 在符合筛选条件时置顶，心宠名称固定并持久化为“测试心宠”。*(已于 2026-07-20 完成)*
- [x] 测试心宠不显示伪造演示历史；实体联调产生的学生原话与心宠回复会幂等保存到真实对话表，并在“对话记录”页签展示。*(已于 2026-07-23 完成实时保存与停止前最终同步)*
- [x] `PetAiProfile` 只配置第一层心宠 AI 的语气、回复风格、主动程度、身份约束和知识范围。*(已于 2026-07-20 完成服务端配置注入)*
- [x] `robot_identity/AGENTS.md` 提供第一层心宠 AI 的公共安全与实体心宠身体能力规则，不再把“小芯”作为实体心宠的固定名称。*(已于 2026-07-20 完成)*
- [x] 第二层“小芯 AI”仍是演示用专业咨询师角色，不接入真实六智能体；但实体心宠学生转写一旦判定为中风险、高风险或危机，会幂等写入真实预警工单系统。*(已于 2026-07-23 接通预警工单)*
- [x] 页面展示结构化处理事件，不展示或声称展示模型的原始思维链。*(已于 2026-07-20 完成)*

## 双层调用流程

1. 实体心宠通过百度 ASR 得到学生话语，并写入实时转写。
2. 对普通话语，第一层心宠 AI 直接使用当前已保存的 `PetAiProfile` 生成回复。
3. 对包含“心情不好”“不想吃饭”等演示触发词的负面话语，ClawBody 写入“检测到负面情绪”和“已转交小芯 AI”事件。
4. 小芯 AI 使用同一阿里云模型、独立专业提示词生成简短、可审核的支持建议。该结果是模拟专业智能体输出，不是诊断结论。
5. 第一层心宠 AI 根据 `PetAiProfile` 将建议转述为学生可直接听到的回复。
6. 百度 TTS 播放最终回复，页面事件流显示 TTS 状态。

## 提示词分层

- 公共基础层：`robot_identity/AGENTS.md`，负责安全边界、真实性、实体心宠身体与动作约束。
- 心宠个性层：服务端从 `PetAiProfile` 生成运行时提示词，浏览器不得直接提交或覆盖提示词。
- 小芯专业层：独立的演示咨询师提示词，只生成结构化建议，不直接面向学生说话。
- 心宠转述层：将原始学生话语和小芯建议交给第一层心宠 AI，生成最终口语回复。

## 实时联调界面

“实时联调”页签保留设备状态和开始/停止按钮，下方按时间显示两类内容：

- 实时对话：学生 ASR 文本与测试心宠最终回复，使用左右气泡区分。
- 协作过程：采用类似开发工具任务流的纵向事件列表，显示“负面情绪识别”“转交小芯 AI”“专业建议”“心宠转述”“TTS 播放”等状态和摘要。
- [x] 实时转写携带 `risk_level`，中风险使用琥珀色、高风险与危机使用红色；学生原话、对应心宠回复、协作过程和左侧学生风险标签保持一致。*(已于 2026-07-21 完成)*
- [x] 会话风险采用只升级策略，避免后续普通话语让风险标签立即闪回；停止会话后重新读取已持久化对话，并按学生原话的最高风险继续展示标签，不修改学生数据库风险等级。刷新后的新对话从最新游标继续检测。*(已于 2026-08-01 完成停止会话后的风险回填与回归测试)*
- [x] 演示对话记录按学生原句进行确定性风险判级，心宠回复继承对应学生消息等级；学习压力、睡眠困扰、焦虑和沟通回避显示中风险，自伤轻生表达显示高风险。*(已于 2026-07-21 完成)*

协作事件仍仅保存在 ClawBody 内存中，最多 100 条。对话转写由 Sentinel 轮询后按确定性消息 ID 幂等保存到 `ChatSession/ChatMessage`，停止会话前再执行一次最终同步，避免遗漏最后一句；学生原话被判定为中风险、高风险或危机时，还会按“学生 + 转写 ID + 时间 + 内容”生成确定性工单 ID，将风险等级、学生原话和建议干预方案写入 `WorkOrder`。重复轮询不会重复保存消息或建单，普通话语和心宠回复不写入工单。

## 错误处理

- ClawBody 不可用时保持现有 `503` 映射和重试入口。
- [x] 实体心宠连接、摄像头和音频初始化在后台线程执行，启动阶段返回 `starting`，不得阻塞 `/health`、状态轮询或 Sentinel 页面。*(已于 2026-07-20 完成并通过真实设备启动验证)*
- [x] 百度 TTS 单声道音频按实体心宠输出声道数转换，连续写入带时间戳的播放缓冲区后再等待整段时长，避免双声道解释错误、缓冲欠载和语音截断。*(已于 2026-07-20 完成并通过音频回归测试)*
- 小芯模型调用失败时记录失败事件，并使用明确标注的演示兜底建议继续完成心宠转述，保证现场演示不中断。
- 只有 `stu-test` 可以启动实体心宠；其他学生仍只能查看和保存心宠个性配置。
- 已保存配置在下一次实体心宠会话启动时生效；运行中的会话不热切换。
