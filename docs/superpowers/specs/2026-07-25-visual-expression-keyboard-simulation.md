# 视觉流表情键盘模拟

## 目标

在多模态数据流的“实时测试”页签中提供可扩展的键盘模拟入口，便于演示视觉流表情识别结果，不影响真实数据模式。

## 验收状态

- [x] `Ctrl + 小键盘 1` 将主要表情与情绪指标切换为“紧张”。*(已于 2026-07-25 完成)*
- [x] `Ctrl + 小键盘 2` 将主要表情与情绪指标切换为“开心”。*(已于 2026-07-25 完成)*
- [x] `Ctrl + 小键盘 3` 将主要表情与情绪指标切换为“发呆”。*(已于 2026-07-25 完成)*
- [x] 快捷键仅在“实时测试”页签生效，并在视觉流卡片内显示操作提示。*(已于 2026-07-25 完成)*
- [x] 模拟状态下三个情绪指标围绕当前快捷键预设基准值持续进行 ±10% 随机浮动，切换快捷键后立即采用新的基准值。*(已于 2026-07-25 完成)*
- [x] 模拟指标每 1.2 秒刷新，进度条填充层使用 1 秒 `transform` 缓动衔接相邻数值，并兼容减少动态效果偏好。*(已于 2026-07-25 调整并通过浏览器计算样式验证)*
