# Reachy 顶部关机按钮设计

## 目标

精简 Reachy 设备调试页的生命周期操作。页面不再展示独立的“设备生命周期”卡片，只在顶部 Ready 状态栏右侧提供一个清晰的“关机”入口。

## 界面设计

- 用红色“关机”按钮替换顶部的“返回心宠管理”按钮。
- 删除底部“设备生命周期”卡片、说明文案和“重启服务”按钮。
- “返回实时联调”继续保留在“音频与联调”卡片中，不改变位置和行为。
- 关机按钮使用现有按钮尺寸、圆角和危险操作配色，保持心图后台管理系统的组件规范。

## 交互与安全

- 点击“关机”先打开现有二次确认弹窗，不直接发送停止命令。
- 若存在学生会话，确认文案继续说明会先停止学生对话，再让机器人安全休眠并关闭 daemon。
- 若没有学生会话，确认文案继续说明机器人会先安全休眠，再关闭 daemon。
- 用户确认后仍发送现有 `{ action: "stop" }` 命令；取消不会产生设备操作。
- 命令执行期间禁用关机按钮，避免重复提交。

## 不在本次范围

- 不修改 Host Bridge、Reachy daemon 或停止设备 API。
- 不删除后端已有的 restart 能力，只移除本页面上的重启入口。
- 不改变动作控制、音频控制、日志或实时联调入口。

## 验收标准

- 顶部 Ready 状态栏右侧只显示“关机”危险操作按钮。
- 页面不再出现“设备生命周期”“重启服务”或底部“停止设备”卡片。
- 页面只保留一个可见的关机入口。
- 点击关机仍显示安全确认弹窗，确认后执行 stop 命令。
- Reachy 相关测试、ESLint 和生产构建通过。
