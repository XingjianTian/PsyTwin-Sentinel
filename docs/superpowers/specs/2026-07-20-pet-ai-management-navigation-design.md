# 心宠 AI 管理中心与 Reachy Mini 集成规范

## 目标

在 Sentinel 内统一查看学生心宠外观、性格和对话能力，并通过内部服务控制 Reachy Mini。ClawBody 不再提供面向用户的独立网页，模型与设备密钥不得进入浏览器。

## 功能状态

- [x] 学生列表支持姓名、学号、班级和风险等级筛选。*(已于 2026-07-20 完成)*
- [x] 心宠详情展示外观、状态、OCEAN 性格和学生心理画像。*(已于 2026-07-20 完成)*
- [x] 每只心宠可保存语气、回复风格、主动程度、系统提示词和知识范围。*(已于 2026-07-20 完成 Prisma 模型、迁移与 API)*
- [x] 性格配置在未导入时以空状态显示，并允许清空全部字段后保存。*(已于 2026-07-27 完成默认空状态、空值校验与持久化修复)*
- [x] 除固定测试学生外，每名学生展示稳定且不同结构的演示对话；测试学生不生成历史记录，所有演示内容均不写入真实聊天表。*(已于 2026-07-20 完成)*
- [x] 测试学生 `stu-test` 固定绑定首版实体 Reachy 会话。*(已于 2026-07-20 按联调对象调整并完成服务端限制)*
- [x] 普通文本走第一层心宠模型；负面文本展示“情绪识别—转交小芯—专业建议—心宠人格化转述”的双层 AI 演示闭环。*(已于 2026-07-20 完成，不创建真实工单或预警)*
- [x] ClawBody 提供带内部密钥的状态、会话、转写、协作事件和文本响应 API。*(已于 2026-07-20 完成)*

## 服务边界

- 浏览器只访问 Sentinel `/api/pet-ai/*`。
- Sentinel 通过 `CLAWBODY_SERVICE_URL` 和 `CLAWBODY_SERVICE_KEY` 访问内部 Python 服务。
- ClawBody 同一时间只运行一个硬件会话，转写只保留内存中的最近 100 条。
- 首版不修改 Pocket API，不持久化演示聊天，不接入真实六智能体风险流程。
