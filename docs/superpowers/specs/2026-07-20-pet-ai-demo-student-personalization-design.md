# 心宠 AI 联调学生与个性化展示设计

## 目标

- [x] 将实体 Reachy 的唯一联调学生从张宇切换为测试学生 `stu-test`。*(已于 2026-07-20 完成接口限制与默认选择)*
- [x] 测试学生使用 Pocket 主心宠标准正面帧，不修改 Pocket 工程。*(已于 2026-07-20 复制标准正面帧到 Sentinel 公共资源)*
- [x] 对默认 OCEAN 全为 50 的心宠生成稳定且有区分度的持久化性格数据。*(已于 2026-07-20 完成默认值识别与一次性回填)*
- [x] 将演示对话改为宽度、轮次、主题和时间均随学生稳定变化的聊天记录。*(已于 2026-07-20 完成聊天流重构与浏览器对比)*

## 数据设计

`PET_AI_DEMO_STUDENT_ID` 默认值改为 `stu-test`。测试学生首次读取心宠快照时仍复用现有心宠创建流程，但展示层固定覆盖为 Pocket 主心宠外观资源。

新增纯函数 `buildStableOceanPersonality(studentId)`，按学生 ID 生成 35–85 的五维值。只有数据库五维全部为 50 时才进行一次性回填；任何已有非默认值保持不变。

演示对话继续不写入 `ChatSession` 或 `ChatMessage`。生成器按学生 ID 稳定选择 2–4 个主题，每个主题包含 1–3 轮消息，并提供不同长度的文本和分散的日期时间。

## 界面设计

对话记录采用连续聊天流：日期分隔、主题标签、学生右侧气泡、心宠左侧气泡。气泡使用 `w-fit` 和最大宽度，真实反映文本长短；发送方通过头像、位置和色彩区分，不再使用同宽卡片。

OCEAN 仍读取数据库值，保留五列紧凑概览；差异来自持久化数据而非浏览器随机数。
