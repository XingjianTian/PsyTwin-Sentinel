### Added

- 集成 LightRAG 心理学知识库管理台到 `AI 配置 -> RAG 向量知识库` 页面，支持在 Sentinel 内直接使用文档管理、知识图谱、检索问答和 API 调试。
- 新增 `docs/LIGHTRAG_INTEGRATION.md`，记录 LightRAG API Key、阿里云百炼模型配置、文档入库流程、图谱验证命令和常见问题。
- 心宠性格配置新增 Markdown 导入功能，支持本地解析并自动填充表达语气、回复风格、主动程度、身份与行为约束和知识范围。*(已于 2026-07-23 完成解析测试与浏览器导入验证)*
- 心宠实时对话检测到中风险、高风险或危机学生原话时，自动幂等创建待处理预警工单；修复实体服务使用 `user` 角色而同步逻辑仅识别 `student`、导致真实中风险转写未建单的问题；侧边栏新增与待处理数量同步的小型泛光数字提醒，新工单进入时徽标单次跳动。*(已于 2026-07-23 完成真实转写格式回归、构建与浏览器验收)*
- 实体心宠实时联调的学生原话与心宠回复现在会幂等保存到 `ChatSession/ChatMessage`，停止会话前执行最终同步；“对话记录”页签会重新读取并展示最多 200 条真实记录。*(已于 2026-07-23 完成持久化回归验证)*
- 测试学生的真实对话记录新增“清空记录”入口和不可恢复提示；服务端限制仅 `stu-test` 可执行，并且只删除实体心宠联调会话。*(已于 2026-07-23 完成权限与交互回归验证)*
- 心宠调试新增完整“表情与动作”库，包含 81 个表情、20 个官方舞蹈和 14 个音乐舞蹈；Sentinel 与 Host Bridge 采用双层动作白名单并映射固定 daemon 数据集。*(已于 2026-07-23 完成两端回归与生产构建，实体动作待人工连机验收)*

- 心宠调试左侧重复的设备连接概览替换为可展开的表情/舞蹈选择器。*(已于 2026-07-23 完成界面与命令链路调整)*
- 心宠调试移除重复的“常规操控”卡，调整为左侧表情动作主区、右侧姿态控制与音频联调区，并压缩音量控件的信息密度。*(已于 2026-07-23 完成布局重构、生产构建与 1367×614 浏览器验收)*
- 心宠调试的表情与动作列表改为固定高度的纵向滑动浏览，取消展开/收起造成的页面高度跳变。*(已于 2026-07-23 完成生产构建与浏览器滚动验收)*
- 心宠调试移除音频控制区的重复标题说明，并让左侧表情动作卡向下撑满至右侧音频卡底部，统一双栏底线。*(已于 2026-07-23 完成生产构建与浏览器像素级对齐验收)*
- 预警工单侧边栏徽标改为未查看新增数：进入工单页面立即清零，之后仅在新工单进入时按新增数量累加并触发跳动，不再持续显示全部待处理数量。*(已于 2026-07-23 完成 12 项聚焦测试、生产构建与浏览器点击验收)*
- RAG 页面由本地模拟文档列表改为嵌入真实 LightRAG WebUI，并提示本地 LightRAG API Key 与阿里云百炼 API Key 的区别。
- 心理学知识图谱默认使用全局标签 `*`，配合 LightRAG WebUI 的高密度图谱布局优化，减少节点和标签重叠。

### Fixed

- 修复 LightRAG WebUI 的 Guest Bearer Token 被 Sentinel 中间件误当作登录 JWT，导致知识库文档和图谱接口持续返回 401 的问题。代理接口现在优先使用 Sentinel 会话 Cookie 鉴权，同时继续阻止未登录访问。*(已于 2026-07-22 通过中间件与代理回归测试)*
- 精简心理学知识库页面，移除重复的外层标题、接入标签、连接状态侧栏和功能说明卡；将知识库品牌与连接状态入口整合到 LightRAG 顶部导航。*(已于 2026-07-23 完成界面整合与回归验证)*
- 修复 Host Bridge 重启后复用已有 daemon 时只恢复运行状态、未恢复电机与媒体快照，导致心宠调试错误显示电机“未知”的问题。*(已于 2026-07-23 完成 111 项 Host Bridge 回归与实时只读状态验证)*
- 修复表情动作接口已接通、但 Sentinel 固定 Host Bridge 路径白名单遗漏新路由，导致网页请求显示“心宠设备控制请求失败”的问题。*(已于 2026-07-23 通过真实浏览器“喜爱”表情链路复测、48 项聚焦测试与生产构建)*
- 修复当前表情数据集已改用 `.ogg`、daemon 1.8.0 仍只识别同名 `.wav`，导致表情有动作却静默无声的问题；Host Bridge 现在从固定本地数据集安全解析并同步播放同名音频。*(已于 2026-07-23 完成 112 项 Host Bridge 回归测试)*
